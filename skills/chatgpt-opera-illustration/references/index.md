## Original visual reference

The user initially supplied a tall reference screenshot bearing a Behance marker: two opera performers with elongated silhouettes, simple ivory faces, broad sleeves, ultramarine robes, a pale pink/mustard/slate background and selective dry print grain. Its strongest lesson was that shape and gesture can feel sophisticated without complex rendering.

The original third-party image file and its author/project URL were not available in the project files at packaging time. It is **not reproduced in this package** and none of the generated images is presented as that original. This description records its visual principles. If the user supplies it later, treat it as an external style reference with its attribution, separate from these generated examples.

Rejected directions included glossy 3D characters, overloaded fantasy ornament, stick-finger vector mannequins, detached feet, realistic frontal doll faces and arbitrary geometric scenery. Do not use those as positive references.

Exact source filenames and SHA-256 hashes of the unmodified example copies are in `provenance.json`. No interview recordings, student manuscripts, private photographs or website credentials are included.
